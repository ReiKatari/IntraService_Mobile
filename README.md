# IntraService Mobile

Нативное Android-приложение для выездных инженеров и исполнителей заявок **IntraService** (`https://intra.lantaservice.com`).

Построено на современном стеке (**Kotlin + Jetpack Compose + Material 3 + CameraX + ML Kit**) с акцентом на минимальный вес APK, плавные анимации, защищённое хранение учётных данных и надёжную работу на мобильных и Wi-Fi сетях.

- **Релизы и готовый APK**: [Releases (`IntraService Mobile 2.0.2`)](https://github.com/ReiKatari/IntraService_Mobile/releases/latest)

---

## Возможности (версия 2.0.2)

1. **Авторизация по логину или E-mail и строгая блокировка без геолокации**
   - При отказе в предоставлении доступа к геолокации **или при отключённой системной геолокации на телефоне** приложение **не допускает авторизацию** до включения геолокации и выводит наглядное предупреждение с кнопкой перехода к настройкам/выдаче разрешения. Если геолокацию отключить уже будучи авторизованным, выполняется немедленный выход на экран входа с уведомлением.
   - Без авторизации отображается только окно входа (с текущей версией ПО и иконкой).
   - Поддерживается вход по логину или корпоративному E-mail с автоматическим сохранением полей при включённом тумблере «Запомнить меня» (`AES-256-GCM` в `AndroidKeyStore`).
   - Все запросы, файлы и смена статуса отправляются строго от лица авторизованного инженера.

2. **Точная геолокация на объекте с полным адресом и защитой от GPS-глушилок**
   - К каждой заявке автоматически прикладывается полный адрес (**индекс, регион, район, населённый пункт, улица, дом**), точные координаты, погрешность в метрах, источник сигнала и время фиксации (`dd.MM.yyyy HH:mm`).
   - **Бесплатный многоступенчатый геокодер без API-ключей**: `OpenStreetMap Nominatim` -> зеркало `Komoot Photon OSM` -> системный `Android Geocoder`. При работе в офлайне полный адрес автоматически доопределяется в момент отправки очереди `PendingOutbox`.
   - **Многоуровневая защита при работе в зоне глушилки (GNSS jamming / spoofing)**:
     - При подавлении или подмене спутников GPS/ГЛОНАСС (диапазон L1/L2) приложение использует триангуляцию **Wi-Fi и сотовых базовых станций (`NETWORK_PROVIDER`)**.
     - **Анти-спуфинг перекрёстная проверка (`GeoAntiSpoofSelector`)**: автоматически выявляет расхождение GPS и Wi-Fi/сотовой сети (`> 1500 м`) или физически невозможные скачки (`> 300 км/ч`) и переключается на надёжную наземную триангуляцию.
     - **Pre-entry контрольная точка**: перед входом в экранированное помещение кэшируется последняя подтверждённая позиция (`last_good_geo.json`); в полной «мёртвой зоне» также проверяются EXIF-координаты фотографии.

3. **Блоки фотодокументов, 5-минутная фиксация формата и распознавание счётчика АВР**
   - При съёмке или выборе фото открывается стилизованное окно выбора формата: **АВР (Акт выполненных работ)**, **Тест-лист**, **Лист конфигурации**.
   - Выбранный формат можно изменить в течение **5 минут** с живым обратным отсчётом прямо на карточке фото, после чего тип документа автоматически фиксируется (`Зафиксировано`).
   - Все вложения распределяются по трём наглядным блокам в карточке заявки (`АВР`, `Тест-лист`, `Лист конфигурации`).
   - **Автоматическое распознавание счётчика копий (`ML Kit Text Recognition` + `AvrCounterParser`)**: при добавлении фото **АВР** приложение прямо на устройстве (офлайн) считывает вписанный счётчик копий и сразу отображает его. Если счётчик не распознан (плохой освещённость, смаз, сложный почерк), сразу открывается окно ручного числового ввода.
   - **Обязательная проверка перед сохранением**: кнопка **«Сохранить»** остаётся неактивной до тех пор, пока не приложены обязательные **АВР**, **Тест-лист** и не определён/введён **счётчик копий**.

4. **Два списка открытых заявок, умная камера и отложенная отправка**
   - Вкладки **«В работе»** и **«Выполнено»** с автообновлением каждые 60 секунд, единым форматом дат `dd.MM.yyyy` и даты со временем `dd.MM.yyyy HH:mm`, полной историей событий (`/api/tasklifetime`) и мгновенным открытием из дискового кэша.
   - Умная камера **CameraX** с живыми индикаторами **Свет / Чёткость / Стабильно** и движком повышения резкости текста **PhotoEnhancerEngine**.
   - **Отложенная офлайн-отправка (`PendingOutbox`)**: сохраняет статус, фото, счётчик и геолокацию с точной датой и временем попытки при сбоях связи и автоматически досылает данные в Интру после восстановления сети.
   - Устойчивый многоступенчатый DNS (`System -> UDP:53 -> DoH -> резервный IPv4`) и автообновление APK из GitHub Releases (автопроверка при запуске, после авторизации, при возврате из фона, восстановлении сети, каждые 5 минут работы и по pull-to-refresh, плюс заметный баннер обновления в списке заявок).

## Сборка из исходников

```properties
# local.properties (не отслеживается Git)
sdk.dir=C\:\\Users\\<USER>\\AppData\\Local\\Android\\Sdk
intra.store.password=<STORE_PASSWORD>
intra.key.alias=<KEY_ALIAS>
intra.key.password=<KEY_PASSWORD>
```

```bash
./gradlew testDebugUnitTest assembleRelease
```

Готовый файл появляется в `app/build/outputs/apk/release/app-release.apk`.

## Стек технологий

- **Kotlin 2.3.21** + Coroutines + Kotlinx Serialization
- **Jetpack Compose** (`1.11.1`) + **Material 3** (`1.4.0`) + **Navigation Compose** (`2.9.8`)
- **CameraX** (`1.6.1`) + **Google ML Kit Text Recognition** (`16.0.1`, on-device)
- **Retrofit 3.0.0** + **OkHttp 4.12.0** + **Coil 2.7.0**
- **AndroidKeyStore AES-256-GCM** для защиты учётных данных
