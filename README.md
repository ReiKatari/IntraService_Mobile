# IntraService Mobile

Нативное Android-приложение для выездных инженеров и исполнителей заявок **IntraService** (`https://intra.lantaservice.com`).

Построено на современном стеке (**Kotlin + Jetpack Compose + Material 3 + CameraX + ML Kit**) с акцентом на минимальный вес APK, плавные анимации, защищённое хранение учётных данных и надёжную работу на мобильных и Wi-Fi сетях.

- **Релизы и готовый APK**: [Releases (`IntraService Mobile 2.2.1`)](https://github.com/ReiKatari/IntraService_Mobile/releases/latest)

---

## Возможности (версия 2.2.1)

1. **Авторизация по логину или E-mail и строгая блокировка без геолокации**
   - При отказе в предоставлении доступа к геолокации **или при отключённой системной геолокации на телефоне** приложение **не допускает авторизацию** до включения геолокации и выводит наглядное предупреждение с кнопкой перехода к настройкам/выдаче разрешения. Если геолокацию отключить уже будучи авторизованным, выполняется немедленный выход на экран входа с уведомлением.
   - Без авторизации отображается только окно входа (с текущей версией ПО и иконкой).
   - Поддерживается вход по логину или корпоративному E-mail с автоматическим сохранением полей при включённом тумблере «Запомнить меня» (`AES-256-GCM` в `AndroidKeyStore`).
   - Все запросы, файлы и смена статуса отправляются строго от лица авторизованного инженера.

2. **Быстрая прогрессивная геолокация на объекте с расширенной карточкой и защитой от GPS-глушилок**
   - К каждой заявке автоматически прикладывается полный адрес (**объект, почтовый индекс, регион, район / округ, населённый пункт, улица, дом**), точные координаты, высота, точность (м и оценка качества), источник сигнала, число активных провайдеров и время фиксации (`dd.MM.yyyy HH:mm`).
   - **Параллельный геокодер без API-ключей и дисковый кэш**: `OpenStreetMap Nominatim`, `Komoot Photon OSM` и `Android Geocoder` опрашиваются параллельно; координаты и быстрый адрес отображаются прогрессивно сразу, а повторные выезды открываются мгновенно из дискового кэша. При работе в офлайне полный адрес автоматически доопределяется в момент отправки очереди `PendingOutbox`.
   - **Многоуровневая защита при работе в зоне глушилки (GNSS jamming / spoofing)**:
     - При подавлении или подмене спутников GPS/ГЛОНАСС (диапазон L1/L2) приложение использует триангуляцию **Wi-Fi и сотовых базовых станций (`NETWORK_PROVIDER`)**.
     - **Анти-спуфинг перекрёстная проверка (`GeoAntiSpoofSelector`)**: автоматически выявляет расхождение GPS и Wi-Fi/сотовой сети (`> 1500 м`) или физически невозможные скачки (`> 300 км/ч`) и переключается на надёжную наземную триангуляцию.
     - **Pre-entry контрольная точка**: перед входом в экранированное помещение кэшируется последняя подтверждённая позиция (`last_good_geo.json`); в полной «мёртвой зоне» также проверяются EXIF-координаты фотографии.

3. **Умная камера A4, автосъёмка, ч/б скан-режим PDF/Док и распознавание счётчика АВР**
   - **Живой контур листа A4 и автосъёмка (0.5 с)**: видоискатель в реальном времени подсвечивает найденный лист A4 поверх камеры, подсказывает точную корректировку («Подойдите ближе», «Выровняйте угол») и автоматически делает снимок, когда лист выровнен и телефон неподвижен 0.5 секунды.
   - **Чёрно-белый «Скан-режим PDF/Док» (`DOCUMENT_SCAN_BW`)**: выравнивание неравномерного освещения и очистка теней от руки/лампы - чистый белый фон, чёткий чёрный текст и компактный размер файла (`~150-300 КБ`) наряду с переключением на цветной и оригинальный варианты на экране проверки.
   - При съёмке или выборе фото открывается стилизованное окно выбора формата: **АВР (Акт выполненных работ)**, **Тест-лист**, **Лист конфигурации** (формат можно сменить в течение 5 минут).
   - **Многопроходное распознавание рукописного счётчика АВР + ручное выделение области**: ML Kit + 2x усиление контраста чернил + B&W нормализация + интерактивное выделение прямоугольника со счётчиком прямо на фото АВР с сохранением шаблона для последующих актов.
   - **Обязательная проверка перед сохранением**: кнопка **«Сохранить»** остаётся неактивной до тех пор, пока не приложены обязательные **АВР**, **Тест-лист** и не определён/введён **счётчик копий**.

4. **Сканер серийного номера и модели МФУ, фоновые push-уведомления и офлайн-очередь**
   - **Сканер оборудования (`ML Kit Barcode + OCR`) и ручной ввод**: фокус по касанию, зум `1x / 2x`, считывание DataMatrix / Code128 / QR-штрихкодов и текста шильдика с дочитыванием модели, подсказка ожидаемого оборудования по заявке, ручной ввод с автоподстановкой и автоматическая сверка с заявкой.
   - **Фоновые уведомления о новых заявках и сроках (`WorkManager`)**: фоновая служба каждые 15 минут проверяет новые назначенные на инженера заявки и приближающиеся дедлайны (`Срок < 1 ч`), отправляя push-уведомление с переходом прямо в заявку по нажатию.
   - **Отложенная офлайн-отправка (`PendingOutbox`)**, автообновление каждые 60 секунд, многоступенчатый DNS (`System -> UDP:53 -> DoH -> резервный IPv4`) и автообновление APK из GitHub Releases.

## Сборка из исходников

```properties
# local.properties (не отслеживается Git)
sdk.dir=C\:\\Users\\<USER>\\AppData\\Local\\Android\\Sdk
intra.store.password=<STORE_PASSWORD>
intra.key.alias=<KEY_ALIAS>
intra.key.password=<KEY_PASSWORD>
```

```bash
./gradlew testDebugUnitTest assembleRelease
```

Готовый файл появляется в `app/build/outputs/apk/release/app-release.apk`.

## Стек технологий

- **Kotlin 2.3.21** + Coroutines + Kotlinx Serialization
- **Jetpack Compose** (`1.11.1`) + **Material 3** (`1.4.0`) + **Navigation Compose** (`2.9.8`)
- **CameraX** (`1.6.1`) + **Google ML Kit Text Recognition** (`16.0.1`) + **ML Kit Barcode Scanning** (`17.3.0`)
- **WorkManager** (`2.10.1`) для фоновых уведомлений о заявках и сроках
- **Retrofit 3.0.0** + **OkHttp 4.12.0** + **Coil 2.7.0**
- **AndroidKeyStore AES-256-GCM** для защиты учётных данных
